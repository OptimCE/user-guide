Sie sind Administrator

Guide utilisateur User guide Gebruikershandleiding Benutzerhandbuch

1 Sie sind Administrator

Übersicht
Sie haben alles, was ein Manager hat, diese Übersicht eingeschlossen, und dazu drei Entscheidungen, die nur Ihnen zustehen: die Module, die die Gemeinschaft nutzt, wer sie mit Ihnen verwaltet, und ihre rechtlichen Angaben.

2 Die Module

Übersicht
Solange Module nicht aktiviert sind, bietet die Übersicht sie unter „Verfügbare Module“ an: „Aktivieren“ abonniert die Gemeinschaft dafür. Ein Manager wird gebeten, sich dafür an Sie zu wenden. Sie finden sie alle unter „Zusatzdienste“.

3 Der Abschnitt „Verwaltung“

Navigation
Als Administrator behalten Sie den Abschnitt „Verwaltung“ der Manager. Auf der Seite „Benutzer“ legen Sie fest, wer die Gemeinschaft mit Ihnen verwaltet.

4 Die Benutzer der Gemeinschaft

Navigation
Klicken Sie im Abschnitt „Verwaltung“ auf „Benutzer“.

5 Einen Manager einladen

Benutzer der Gemeinschaft
Nur ein Administrator kann einen Manager hinzufügen: „Einen Manager einladen“ sendet ihm eine Einladung per E-Mail, die er in seinen Einladungen annimmt.

6 Einladungen und Rollen

Benutzer der Gemeinschaft
„Ausstehende Einladungen anzeigen“ zeigt, wer noch nicht geantwortet hat. In der Liste können nur Sie die Rolle eines Benutzers ändern — Mitglied, Manager oder Administrator — oder ihn aus der Gemeinschaft entfernen.

7 Der Abschnitt „Gemeinschaft“

Navigation
Der Abschnitt „Gemeinschaft“ führt zur Übersicht, zur Gemeinschaftsinfo und zu ihren Zusatzdiensten. Auf der Seite „Gemeinschaftsinfo“ stehen die rechtlichen Angaben, die nur Sie ändern können.

8 Die Gemeinschaftsinfo

Navigation
Klicken Sie im Abschnitt „Gemeinschaft“ auf „Gemeinschaftsinfo“.

9 Die rechtlichen Angaben

Gemeinschaftsinfo
Mitglieder und Manager lesen diese Angaben; nur Sie können sie ändern. „Bearbeiten“ öffnet den Namen, die Beschreibung, die Adresse, die Unternehmensnummer und die IBAN — was danach auf den Rechnungen und den offiziellen Dokumenten erscheint.
