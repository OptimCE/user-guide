Abonneren op een annexdienst

Guide utilisateur User guide Gebruikershandleiding Benutzerhandbuch

1 Annexdiensten openen

Navigatie
Klik in de sectie “Gemeenschap” van de zijbalk op “Annexdiensten” om de aanvullende modules te openen die voor de gemeenschap beschikbaar zijn.

2 Geen module geactiveerd

Annexdiensten
De pagina “Annexdiensten” is leeg: er is nog geen enkele aanvullende module geactiveerd voor deze gemeenschap.

3 Module toevoegen

Abonnement
Klik rechtsboven op “Module toevoegen” om de catalogus te openen van de modules die voor deze gemeenschap beschikbaar zijn.

4 Een module kiezen

Abonnement
Het dialoogvenster toont de beschikbare modules. Hier wordt de module “Generatie van verdeelsleutels” aangeboden, samen met de beschrijving ervan.

5 De module activeren

Abonnement
Klik op “Toevoegen” naast de module “Generatie van verdeelsleutels” om de module voor de gemeenschap te activeren.

6 Module geactiveerd

Abonnement
De kaart “Generatie van verdeelsleutels” verschijnt in het raster met de badge “Geactiveerd”: de module is nu toegankelijk vanaf deze pagina.
