Attach a file to a document

Attach a file prepared outside OptimCE to a procedure's document and keep it as an official version.

For ManagerAdministrator

  • Step by step
  • Interactive
Step 1 of

Attach a file to a document

1 Open the administrative documents

Navigation
In the sidebar, click "Administrative documents".

2 Open the procedure

Procedures
Click the procedure to open its page. Its button already names the next action: here, completing the documents.

3 Attach a file

Documents
A document signed, received or prepared outside OptimCE is attached with the upload icon, on that document's row.

4 Choose the file

Upload a version
Drop the file in the dedicated area, or click to pick it from your computer.

5 Upload

Upload a version
Submit: the file becomes the document's current version. It is kept as it is, with its fingerprint, and will never be modified.

6 The document is ready

Documents
The document turns "Ready" and can be downloaded. A new file would add a version without erasing the previous one. Once every required document is ready, the procedure turns "Ready" by itself and offers to send it.
